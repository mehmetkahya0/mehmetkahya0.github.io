01 — About

I work where hardware meets software, and teach machines to see.

I'm an Electrical-Electronics Engineering student who has been writing code for seven years, and I still get the same rush the first time something I built actually works. My GitHub shows that curiosity: more than 90 public repositories, from a curated AI catalog with nearly 500 stars to flight simulators, computer-vision pipelines and a LiDAR-guided robot vacuum.

I'm most at home in Python and JavaScript/TypeScript, and happy to reach for Kotlin, C++ or Swift when a project calls for it. Lately I've been going deep on AI-assisted development (desktop tools around Claude Code, MCP servers, browser extensions), while the engineer in me keeps pulling toward autonomous systems, robotics and space technology. I'm looking for teams where I can learn fast and ship things people actually use.

  • Location Izmir, Turkey
  • Focus AI, Computer Vision, Robotics, Web
